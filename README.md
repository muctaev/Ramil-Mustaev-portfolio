\# plat.website — Ramil Mustaev portfolio



Static single-page portfolio (React + Tailwind via CDN, Babel standalone).



\## Local preview

Babel fetches js/app.jsx over HTTP, so a local server is required:

&#x20;   npx serve .

&#x20;   # or: python -m http.server 8000

Then open http://localhost:3000 (or :8000). Double-clicking index.html will NOT work.
